# 功能规格与扩展范围

## 已实现

| 模块 | 功能 |
| --- | --- |
| 首页 | 品牌头图、活动文案、取餐门店、商品分类 |
| 商品 | 推荐标签、价格、介绍、温度与糖度选择 |
| 购物袋 | 多规格合并、数量增减、小计和合计 |
| 下单 | 创建订单、订单编号、数量与金额记录 |
| 订单 | 制作状态、进度展示、删除记录、再次点单 |
| 数据 | 购物袋与订单本地持久化 |

## 可报价扩展

- 微信登录、手机号授权和会员体系
- 微信支付、退款与支付结果通知
- 多门店、定位、营业时间和自提时间选择
- 后台商品、规格、库存、上下架和价格管理
- 优惠券、积分、储值、拼单和营销活动
- 订单打印、叫号、订阅消息和配送平台对接

## 样例边界

当前版本使用本地模拟数据，不包含真实支付、服务端数据库、管理后台和生产环境监控。这些内容应在客户需求确认后单独评估。
