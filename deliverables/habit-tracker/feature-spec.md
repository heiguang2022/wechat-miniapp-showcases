# 功能规格与扩展范围

## 已实现

| 模块 | 功能 |
| --- | --- |
| 今日 | 日期、周视图、完成进度、习惯列表和打卡 |
| 新建 | 名称输入、图标/配色预设、创建习惯 |
| 统计 | 月度坚持、周趋势、最佳记录和完成率 |
| 我的 | 个人信息摘要、习惯管理、删除和数据恢复 |
| 反馈 | 完成状态、进度更新、短震动和提示消息 |
| 数据 | 自定义习惯与打卡状态本地持久化 |

## 可报价扩展

- 微信登录、跨设备云同步和数据备份
- 订阅消息、日历提醒和未完成提醒
- 自定义周期、目标次数、补签和请假规则
- 好友监督、家庭小组、排行榜和勋章体系
- AI 计划建议、健康数据接入和周报/月报
- 课程、训练营、付费会员和运营管理后台

## 样例边界

当前趋势图和月度数据为演示数据，不包含服务端统计、系统级定时提醒、健康平台数据和多端同步。
