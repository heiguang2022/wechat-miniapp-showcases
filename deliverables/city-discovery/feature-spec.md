# 功能规格与扩展范围

## 已实现

| 模块 | 功能 |
| --- | --- |
| 发现 | 城市主题、分类筛选、活动卡片和标签 |
| 收藏 | 收藏/取消收藏、收藏列表、状态同步 |
| 详情 | 日期、地点、介绍、报名入口 |
| 报名 | 创建唯一票券、防重复报名、状态提示 |
| 票夹 | 活动信息、票码、取消报名 |
| 数据 | 收藏与票券本地持久化 |

## 可报价扩展

- 城市切换、地图定位、距离排序和路线导航
- 活动搜索、日历筛选、专题推荐和内容分享
- 微信登录、实名报名、联系人和参与人数
- 微信支付、退款、优惠码和电子发票
- 二维码验票、工作人员核销端和入场统计
- 主办方后台、活动发布、内容审核和数据看板

## 样例边界

当前活动、库存和票码均为本地模拟数据，不包含真实支付、服务端防超卖、二维码扫码核销和运营后台。
