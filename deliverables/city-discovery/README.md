# 漫游城市｜活动发现小程序样例

面向城市活动、文旅、本地生活、展览机构和社区运营的内容发现产品。样例覆盖“发现—收藏—详情—报名—票夹”的完整用户路径。

![漫游城市首页](./cover.png)

## 核心卖点

- 城市感视觉首页和策划主题主视觉
- 按展览、市集、演出、体验筛选活动
- 活动收藏、详情介绍和即时反馈
- 免费预约或付费报名的统一交互入口
- 个人票夹、票码展示和取消报名
- 收藏和票券本地持久化，适合离线提案演示

## 技术方案

- 技术栈：WXML、WXSS、JavaScript、微信 Storage
- 页面结构：发现、收藏和票夹三种业务状态
- 数据模型：活动、标签、收藏状态、报名票券和唯一票码
- 工程特点：原生轻量、无 npm 依赖、导入即运行

正式项目可继续接入 CMS、地图、定位、内容审核、支付、核销和主办方管理后台。
